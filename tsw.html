1. Main Menu & Options XML Tweaks

Edit C:\Program Files (x86)\Funcom\Secret World Legends\Data\Gui\Default\Views\MainMenu\Window.xml:

<?xml version="1.0" encoding="UTF-8" standalone="yes" ?>
<!-- $Change: 600955 $ (must be within the first 200 characters of the file) -->

<Root fadein_duration="0"
      fadeout_duration="0"
      viewslide_duration="0"
      viewfade_duration="0"
      alpha="0" />

Set the file to Read-Only.

Then delete: C:\Program Files (x86)\Funcom\Secret World Legends\Data\Gui\Default\Views\MainMenu\Window.bxml

Next, edit C:\Program Files (x86)\Funcom\Secret World Legends\Data\Gui\Default\Views\MainMenu\Options.xml:

Search for the line containing gmlevel="-1" and remove that attribute so it looks like this:

<OptionSubGroup title="<localized token=MainMenu_Options_Debug />">

Set the file to Read-Only, then delete Options.bxml in the same folder.

Note: The .bxml files are generated automatically after .xml files are read. Deleting them forces the game to regenerate them with your custom XML edits.

2. Compatibility Settings & DirectX 11 Crash Fix

The primary executable that requires compatibility settings is ClientPatcher.exe. If launching via a shortcut, configure these settings on the shortcut properties as well:

  • Right-click ClientPatcher.exe → Send to → Desktop (create shortcut)
  • Right-click desktop shortcut → Properties
  • Advanced → Check Run as administrator
  • Set Run to Maximized
  • Go to Compatibility tab → Click Change settings for all users

Note: If starting via Steam or another wrapper (e.g. PatcherSetup.exe), compatibility options must be set there too. When started via ClientPatcher.exe, compatibility modes transfer directly to SecretWorldLegends.exe / SecretWorldLegendsDX11.exe.

Fixing DX11 Crash Issues

Apply Properties → Compatibility settings to the patcher executables (bold paths below):

  • C:\Program Files (x86)\Funcom\Secret World Legends\ClientPatcher.exe
  • C:\Program Files (x86)\Funcom\Secret World Legends\PatcherSetup.exe
  • C:\Program Files (x86)\Funcom\Secret World Legends\SecretWorldLegends.exe
  • C:\Program Files (x86)\Funcom\Secret World Legends\SecretWorldLegendsDX11.exe
  • C:\Program Files (x86)\Funcom\The Secret World\ClientPatcher.exe
  • C:\Program Files (x86)\Funcom\The Secret World\TheSecretWorld.exe
  • C:\Program Files (x86)\Funcom\The Secret World\TheSecretWorldDX11.exe

In-Game Modding Instructions

Mods must be extracted into single unnested folders inside:

C:\Program Files (x86)\Funcom\Secret World Legends\Data\Gui\Custom\Flash

Example Structure for "Clickable Nametags":

C:\...\Flash\ClickableNametags\CharPrefs.bxml
C:\...\Flash\ClickableNametags\CharPrefs.xml
C:\...\Flash\ClickableNametags\ClickableNametags.swf
C:\...\Flash\ClickableNametags\Modules.bxml
C:\...\Flash\ClickableNametags\Modules.xml

Important: Ensure mod files reside directly inside a single subfolder under Flash/. Do not leave double-nested directories from zip archives.

Mod customization tip: In Meeehrpack, removing AutoPet.swf leaves AutoSprint.swf functional while avoiding pet summons glitches.

Windows Defender Exclusion Fix

To avoid false positives from Defender during updates, exclude your main installation directory in Windows Settings (Win + I → Update & Security → Windows Security → Virus & threat protection → Manage settings → Exclusions):

  • C:\Program Files (x86)\Funcom
  • C:\Program Files (x86)\Steam\steamapps\common (or custom library folder e.g. D:\SteamLibrary)
